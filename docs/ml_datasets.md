# UniShield AI -- ML Datasets Documentation

This document records the provenance, format, and ingestion mechanisms for the datasets used to train UniShield's ML models.

## 1. DGA Detection Dataset

**Provenance:**
- **Benign:** Majestic Million Top 1M Domains
- **Malicious (DGA):** 360Netlab DGA Feed

**Acquisition:**
The dataset can be generated by running `scripts/datasets/download_dga.py`. This script downloads the latest feeds, extracts UniShield's canonical features (entropy, length, character ratios), and saves the preprocessed data to `data/processed/dga_dataset.csv`.

**Features Extracted:**
- `dns_query_length`
- `dns_entropy`
- `dns_ngram_entropy`
- `dns_digit_ratio`
- `dns_unique_char_count`
- `dns_alpha_ratio`
- `dns_hyphen_ratio`

## 2. Encrypted Session Detection Dataset

**Provenance:**
- **Base Dataset:** CIC-IDS2017 (Canadian Institute for Cybersecurity)
- **Preprocessed:** Reduced feature set mapping to UniShield's SPLT (Sequence of Packet Lengths and Times) requirements.

**Acquisition:**
The dataset is available at `data/processed/encrypted_dataset.csv`. The `scripts/datasets/download_encrypted.py` script can also be used if dynamic fetching from a remote repository is configured.

**Features Extracted:**
- Packet counts, byte counts, flow duration.
- Inter-arrival time (IAT) statistics (mean, cv).
- SPLT arrays (`splt_size_0` to `splt_size_19`, `splt_time_0` to `splt_time_19`).

## 3. C2 Beacon Detection Dataset (User-Supplied)

**Provenance:**
Due to licensing and payload distribution restrictions, a real-world C2 beacon dataset (such as CTU-13 or Stratosphere IPS) is **not bundled or automatically downloaded**. By default, the C2 Beacon detector runs in **STATISTICAL mode** using advanced heuristic scoring.

**Ingestion Mechanism:**
If you wish to enable the optional `C2IsolationForest` anomaly detection model, you must provide your own dataset and train the model using the following steps:

1. **Obtain Data:** Download a botnet capture dataset containing periodic beaconing (e.g., CTU-13).
2. **Preprocess:** Convert the PCAPs or flow logs into UniShield's `BeaconFeatures` array format (a 13-element vector containing connection counts, inter-connection interval stats, and byte stats).
3. **Train:** Load the feature arrays into a Python script and call the `C2IsolationForest.train()` method.
4. **Save Model:** Call `save("models/trained/c2_isolation_forest.pkl")` and update the `c2_beacon.py` configuration to point to this path.
